# 决策沙盘（Decision Sandbox）

> 把抽象决策变成可拖拽的物理沙盘，用具身认知帮大学生在 10 分钟内做出"考虑更全、后悔更少"的选择。

**v1 PC 端** · 课程设计项目 · 作者：230200503 肖权 · 撰写：2026-06

---

## 这是什么

一个**本地优先**的 PC 端决策辅助工具。决策档案只存在浏览器的 localStorage；只有用户主动使用可选 AI 功能并确认隐私披露后，才会把披露范围内的决策信息发送给 DeepSeek。

当你面对"秋招 offer A 还是 B" / "选毕设课题甲还是乙" / "周末学吉他还是学 Python"这种"差不多、说不出哪个更好"的纠结时，把选项拖进沙盘，AI 帮你识别漏看的维度，给你打分、配权重、推演未来，最后给一个**带理由的推荐**——但**最终选哪个永远是你自己**。

### 解决的 3 大痛点

| 痛点 | 例子 | 沙盘怎么解 |
|---|---|---|
| **信息盲区** | "我考虑不全" | 模板维度 + A6 AI 推荐更多维度 |
| **权重失衡** | "我拍脑袋" | 维度评分 + 权重滑块，**归一化**（你不用算和=1） |
| **后悔焦虑** | "我怕选错" | 时间轴推演 + 决策档案（事后回看）+ A7 AI 综合推荐 |

---

## 5 核心功能

按使用顺序：

| 步骤 | 名称 | 作用 |
|---|---|---|
| **F1** | 拖拽上盘 | 把 2-6 个选项拖到沙盘上，**拖拽顺序就是优先级** |
| **F2** | 维度雷达 | 选评估角度（薪资/成长性/团队氛围…），AI 可推荐你漏掉的 |
| **F3** | 维度评分 | 给每个选项在每个维度上 0-10 分 |
| **F4** | 权重配比 | 滑块调权重，**系统自动归一化**（无需心算） |
| **F5** | 时间轴推演 | 预演未来 N 个月，每个节点打"积极/风险/中性"标签 |
| **F6** | 锁定决策 | 选项排名 + 决策理由 → 锁定生成档案（可解锁再改） |

完整详细需求见 [`../PRD_决策沙盘.md`](../PRD_决策沙盘.md)（v2.2）。

## 2 个 AI 增强（可选）

| 编号 | 名称 | 位置 | 输入 | 输出 |
|---|---|---|---|---|
| **A6** | AI 推荐更多维度 | F2 步骤内 | 选项名 + 已选维度 | 3-5 个候选维度 + 1 句相关性 |
| **A7** | AI 综合推荐 | F7 步骤右栏 | 选项 + 评分 + 权重 + 理由 | 1 个推荐选项 + 3 条理由 |

> ⚠️ **AI 是草稿，不是决策**。用户最终挑选权永远在自己。

### 隐私披露

- **送 LLM 的内容**：选项名 + 维度评分 + 权重 + 决策理由（A7）
- **不送的内容**：时间轴、决策档案、你的身份信息
- **Key 存储**：默认只存当前浏览器会话；用户主动选择“记住此设备”时才存 localStorage
- **Key 转发**：Vercel / Netlify Function 仅在单次请求中把用户 Key 转发给 DeepSeek，不持久化、不记录
- **生产环境**：Vercel 与 Netlify 均提供同源 `/api/llm` Serverless Function

## 本地跑起来

需要 [Node.js](https://nodejs.org/) 18+。

```bash
# 1. 安装依赖
npm install

# 2. 启动 dev server
npm run dev
# → http://localhost:5173

# 3. 浏览器打开 → 设置 → AI 推荐 → 填入 DeepSeek API Key
#    （没填也能用，AI 按钮会引导去设置）
```

### 不填 API Key 也能用

5 核心功能**完全不需要 AI**。本地所有计算在前端做（localStorage 持久化）。

### 填了 Key 之后

A6 / A7 才会出现。点"AI 推荐"按钮会先弹**隐私披露**——同意后才发请求。

## 技术栈

- **框架**：React 18 + TypeScript + Vite 6
- **样式**：Tailwind CSS v4（CSS-first 配置，无 `tailwind.config.js`）
- **动画**：motion (framer-motion 后继)
- **图标**：lucide-react
- **图表**：recharts（雷达图）
- **拖拽**：motion `Reorder`（F1 排序）
- **存储**：localStorage
- **LLM**：DeepSeek（用户自带 Key；本地 Vite 代理，线上 Vercel / Netlify Function）

## 设计理念

> 决策沙盘用空间代替记忆，拖拽代替输入，结构代替直觉，
> 预演代替承受，识别代替回忆，归一化代替算数。
> 帮你绕开工作记忆瓶颈，做出考虑更全、后悔更少的选择。

基于认知科学：空间外化、识别优于回忆、预演代替承受、具身认知。
**不引入**任何账号系统、云同步、社交功能。

---

## 不做什么

- ❌ 不做情感咨询 / 心理治疗
- ❌ 不做账号系统 / 云同步（v1 纯本地）
- ❌ 不做团队决策 / 多人投票（V2 候选）
- ❌ 不做长期目标规划（仅做"当下选哪个"）
- ❌ 不做通用笔记 / 待办
